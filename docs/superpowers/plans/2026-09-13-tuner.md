# Étude Tuner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A chromatic tuner screen with instrument presets, per-string targets, and an animated colour-coded readout, fed by a new local Expo module that taps the microphone.

**Architecture:** Three layers with hard boundaries. `modules/pitch-input` is a dumb native mic tap that exposes the last 4096 frames of Int16 PCM through a synchronous `read()` — no DSP in Kotlin or Swift. `src/lib/tuner-math.ts` holds every piece of logic as pure functions, so `scripts/check-tuner.ts` can exercise the whole algorithm on Windows with synthesized waveforms and no device. `src/app/tuner.tsx` polls, animates, and renders.

**Tech Stack:** Expo SDK 57, React Native 0.86, Expo Modules API (Kotlin + Swift), `react-native-reanimated@4.5.1`, `react-native-svg@15.15.4`, `expo-haptics`, `expo-audio` (permissions only), TypeScript 6.

**Spec:** `docs/superpowers/specs/2026-09-13-tuner-design.md`

## Global Constraints

- **No new npm dependencies.** Everything needed is already in `package.json`.
- **Expo SDK 57.** Read `https://docs.expo.dev/versions/v57.0.0/` before writing against any Expo API — per `AGENTS.md`, the API surface changed.
- **Typed arrays:** only `Uint8Array` ↔ `Data` (iOS) / `ByteArray` (Android) is a documented Expo Modules convertible. Never send `Float32Array` across the bridge, and never put audio in an event payload.
- **Analysis window: 4096 frames at 44.1 kHz**, decimated by 4 to an effective 11.025 kHz / 1024 samples before YIN.
- **Pitch search range: 38–1000 Hz.**
- **Native module must be optional:** export via `requireOptionalNativeModule`, exactly like `modules/metronome-controls/src/MetronomeControlsModule.ts`. A missing native side shows a card, never a crash.
- **All user-facing strings** go in `src/locales/en.json` and `src/locales/de.json`. No literals in JSX.
- **Theme tokens only** — colours come from `useTheme()`/`themed()` in `src/lib/theme.ts`. No hex literals in components.
- **`reduceMotion` must be honoured** by every animation, matching `src/components/motifs.tsx`.
- **Settings keys are flat** on the `Settings` type in `src/lib/store.tsx` (see the `metro*` keys) so the shallow seed merge backfills old installs.
- Commit after every task.

```ts
// Tuner math: equal-temperament note conversion, instrument string targets,
// and YIN pitch detection. Pure — no React, no native, so scripts/check-tuner.ts
// can exercise all of it on a desktop with synthesized waveforms.

/** Sharps only. One spelling per pitch class; there is no key context to guess from. */
const NAMES = ['C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B'];

export const DEFAULT_REF_A = 440;

export type Note = {
  /** e.g. 'A' or 'A#' — render '#' as '♯' at the view layer. */
  name: string;
  /** Scientific pitch notation: middle C is C4. */
  octave: number;
  midi: number;
  /** Signed distance to the nearest semitone, -50..50. */
  cents: number;
};

export const midiToHz = (midi: number, refA = DEFAULT_REF_A) => refA * 2 ** ((midi - 69) / 12);

export function toNote(hz: number, refA = DEFAULT_REF_A): Note {
  const exact = 69 + 12 * Math.log2(hz / refA);
  const midi = Math.round(exact);
  return {
    name: NAMES[((midi % 12) + 12) % 12],
    octave: Math.floor(midi / 12) - 1,
    midi,
    // exact - midi is within ±0.5 by construction; the clamp guards float edges
    cents: Math.max(-50, Math.min(50, (exact - midi) * 100)),
  };
}

export type Instrument = {
  id: string;
  /** Open-string MIDI numbers, low to high. Empty means free chromatic. */
  strings: number[];
};

// ponytail: a flat table, not a presets engine. Adding an instrument is one line.
export const INSTRUMENTS: Instrument[] = [
  { id: 'chromatic', strings: [] },
  { id: 'guitar', strings: [40, 45, 50, 55, 59, 64] }, // E2 A2 D3 G3 B3 E4
  { id: 'bass', strings: [28, 33, 38, 43] }, // E1 A1 D2 G2
  { id: 'violin', strings: [55, 62, 69, 76] }, // G3 D4 A4 E5
  { id: 'viola', strings: [48, 55, 62, 69] }, // C3 G3 D4 A4
  { id: 'cello', strings: [36, 43, 50, 57] }, // C2 G2 D3 A3
  { id: 'ukulele', strings: [67, 60, 64, 69] }, // G4 C4 E4 A4, reentrant
];

/** Index of the closest open string, or null past 3 semitones so a stray note
 *  doesn't yank the highlight across the instrument. */
export function nearestString(midi: number, strings: number[]): number | null {
  let best: number | null = null;
  let bestDist = Infinity;
  for (const [i, s] of strings.entries()) {
    const d = Math.abs(s - midi);
    if (d < bestDist) [best, bestDist] = [i, d];
  }
  return bestDist <= 3 ? best : null;
}
```

import { detectPitch, smooth, WINDOW } from '../src/lib/tuner-math.ts';

const RATE = 44100;

/** A pure tone, plus optional harmonics at 1/n amplitude (a sawtooth-ish timbre). */
function tone(hz: number, harmonics = 1, amp = 0.5): Float32Array {
  const buf = new Float32Array(WINDOW);
  for (let i = 0; i < WINDOW; i++) {
    let v = 0;
    for (let h = 1; h <= harmonics; h++) v += Math.sin((2 * Math.PI * hz * h * i) / RATE) / h;
    buf[i] = v * amp;
  }
  return buf;
}

const centsOff = (got: number, want: number) => 1200 * Math.log2(got / want);

// --- detectPitch: accuracy across the range ---
for (const hz of [41.2, 82.4, 110, 196, 220, 440, 442]) {
  const p = detectPitch(tone(hz), RATE);
  assert.ok(p, `detect ${hz}`);
  near(centsOff(p!.hz, hz), 0, 2, `${hz} Hz within 2 cents`);
}

// The decimate-by-4 assumption lives or dies here. If these fail, decimate by 2.
for (const hz of [659.26, 880]) {
  const p = detectPitch(tone(hz), RATE);
  assert.ok(p, `detect ${hz}`);
  near(centsOff(p!.hz, hz), 0, 2, `${hz} Hz within 2 cents (decimation guard)`);
}

// --- harmonics must not fool it into the octave above ---
const saw = detectPitch(tone(196, 8), RATE);
assert.ok(saw, 'detect sawtooth');
near(centsOff(saw!.hz, 196), 0, 2, 'sawtooth G3 fundamental, not a harmonic');
assert.equal(toNote(saw!.hz).name, 'G');
assert.equal(toNote(saw!.hz).octave, 3);

for (let i = 0; i < WINDOW; i++) noise[i] = Math.random() * 2 - 1;
assert.equal(detectPitch(noise, RATE), null, 'white noise rejected');
assert.equal(detectPitch(new Float32Array(WINDOW), RATE), null, 'silence rejected');

// a tone too quiet to be a real note is rejected before YIN even runs
assert.equal(detectPitch(tone(440, 1, 0.0005), RATE), null, 'near-silent tone rejected');

```ts
/** Frames of 44.1 kHz audio per analysis — ~93 ms. Two periods of the lowest
 *  supported note (bass low E, 41.2 Hz) must fit. */
export const WINDOW = 4096;
/** Below bass low E (41.2 Hz). */
export const MIN_HZ = 38;
/** Above violin E5 (659 Hz) with headroom. */
export const MAX_HZ = 1000;

/** Naive YIN is O(window × lags): ~2.3M multiply-accumulates per analysis at
 *  44.1 kHz, 25×/sec — too slow for Hermes. Averaging groups of 4 samples (a box
 *  filter, which also anti-aliases) drops that to ~290K for the same 93 ms of
 *  audio. Costs lag resolution up high, which the parabolic step recovers;
 *  check-tuner.ts guards it with sub-2-cent assertions at 659 and 880 Hz.
 *  ponytail: if those ever fail, set this to 2. */
const DECIMATION = 4;
/** YIN's absolute threshold. Below it we call the dip a real period. */
const THRESHOLD = 0.15;
/** RMS floor — quieter than this is a room, not a note. */
const MIN_RMS = 0.005;

export type Pitch = { hz: number; clarity: number };

export function detectPitch(samples: Float32Array, sampleRate: number): Pitch | null {
  // Cheap gate first: no point running YIN on silence.
  let sum = 0;
  for (let i = 0; i < samples.length; i++) sum += samples[i] * samples[i];
  if (Math.sqrt(sum / samples.length) < MIN_RMS) return null;

  const rate = sampleRate / DECIMATION;
  const n = Math.floor(samples.length / DECIMATION);
  const x = new Float32Array(n);
  for (let i = 0; i < n; i++) {
    let acc = 0;
    for (let k = 0; k < DECIMATION; k++) acc += samples[i * DECIMATION + k];
    x[i] = acc / DECIMATION;
  }

  const minLag = Math.max(2, Math.floor(rate / MAX_HZ));
  const maxLag = Math.min(Math.floor(n / 2), Math.ceil(rate / MIN_HZ));
  if (maxLag <= minLag) return null;

  // YIN step 1-2: difference function, then cumulative mean normalization.
  const cmnd = new Float32Array(maxLag + 1);
  cmnd[0] = 1;
  let running = 0;
  for (let lag = 1; lag <= maxLag; lag++) {
    let d = 0;
    for (let i = 0; i < n - maxLag; i++) {
      const delta = x[i] - x[i + lag];
      d += delta * delta;
    }
    running += d;
    cmnd[lag] = running === 0 ? 1 : (d * lag) / running;
  }

  // YIN step 3: first lag under the threshold, walked down to its local minimum.
  // "First, not smallest" is what stops it locking onto a harmonic an octave up.
  let lag = -1;
  for (let i = minLag; i <= maxLag; i++) {
    if (cmnd[i] < THRESHOLD) {
      while (i + 1 <= maxLag && cmnd[i + 1] < cmnd[i]) i++;
      lag = i;
      break;
    }
  }
  if (lag < 0) return null;

  // YIN step 4: parabolic interpolation around the dip for sub-sample precision.
  // This is what buys back the resolution decimation gave away.
  const a = cmnd[lag - 1] ?? cmnd[lag];
  const b = cmnd[lag];
  const c = cmnd[lag + 1] ?? cmnd[lag];
  const denom = 2 * (2 * b - a - c);
  const refined = denom === 0 ? lag : lag + (a - c) / denom;

  const hz = rate / refined;
  if (hz < MIN_HZ || hz > MAX_HZ) return null;
  return { hz, clarity: 1 - b };
}

/** Median of the readings on hand. Median, not mean: a single octave error is
 *  discarded outright instead of being averaged into the answer. */
export function smooth(history: number[]): number {
  if (history.length === 0) return 0;
  const sorted = [...history].sort((a, b) => a - b);
  const mid = sorted.length >> 1;
  return sorted.length % 2 ? sorted[mid] : (sorted[mid - 1] + sorted[mid]) / 2;
}
```

- [ ] **Step 2: Android module**

`modules/pitch-input/android/src/main/java/expo/modules/pitchinput/PitchInputModule.kt`:

```kotlin
package expo.modules.pitchinput

import android.media.AudioFormat
import android.media.AudioRecord
import android.media.MediaRecorder
import android.os.HandlerThread
import expo.modules.kotlin.modules.Module
import expo.modules.kotlin.modules.ModuleDefinition
import java.nio.ByteBuffer
import java.nio.ByteOrder

private const val RATE = 44100
/** Frames per analysis window — must match WINDOW in src/lib/tuner-math.ts. */
private const val WINDOW = 4096

/**
 * A microphone tap and nothing else. Pitch detection lives in
 * src/lib/tuner-math.ts so it is written once, in one language, and can be
 * tested without a device. This class owns a ring buffer and hands JS the
 * newest WINDOW frames whenever it asks.
 */
class PitchInputModule : Module() {
  private var recorder: AudioRecord? = null
  private var thread: HandlerThread? = null
  private var running = false

  // Ring of the newest WINDOW frames. Guarded by `lock` because the capture
  // thread writes it while the JS thread reads it.
  private val ring = ShortArray(WINDOW)
  private var writeIndex = 0
  private var filled = false
  private val lock = Any()

  override fun definition() = ModuleDefinition {
    Name("PitchInput")

    Property("sampleRate") { RATE }
    Property("isRecording") { running }

    Function("start") { start() }
    Function("stop") { stop() }

    Function("read") {
      synchronized(lock) {
        if (!filled) return@Function ByteArray(0)
        // Little-endian Int16, oldest first, so JS can view it as an Int16Array.
        val out = ByteBuffer.allocate(WINDOW * 2).order(ByteOrder.LITTLE_ENDIAN)
        for (i in 0 until WINDOW) out.putShort(ring[(writeIndex + i) % WINDOW])
        out.array()
      }
    }

    OnDestroy { stop() }
  }

  private fun start() {
    if (running) return
    val minBuf = AudioRecord.getMinBufferSize(
      RATE, AudioFormat.CHANNEL_IN_MONO, AudioFormat.ENCODING_PCM_16BIT
    )
    if (minBuf <= 0) throw IllegalStateException("mic unavailable")

    // VOICE_RECOGNITION, not VOICE_COMMUNICATION: the latter applies AGC and
    // noise suppression, which colour the very pitch we are trying to measure.
    val rec = AudioRecord(
      MediaRecorder.AudioSource.VOICE_RECOGNITION,
      RATE,
      AudioFormat.CHANNEL_IN_MONO,
      AudioFormat.ENCODING_PCM_16BIT,
      maxOf(minBuf, WINDOW * 2 * 2)
    )
    if (rec.state != AudioRecord.STATE_INITIALIZED) {
      rec.release()
      throw IllegalStateException("mic unavailable")
    }

    synchronized(lock) {
      writeIndex = 0
      filled = false
    }
    recorder = rec
    running = true
    rec.startRecording()

    val t = HandlerThread("pitch-input").also { it.start() }
    thread = t
    android.os.Handler(t.looper).post {
      val chunk = ShortArray(1024)
      while (running) {
        val n = rec.read(chunk, 0, chunk.size)
        if (n <= 0) continue
        synchronized(lock) {
          for (i in 0 until n) {
            ring[writeIndex] = chunk[i]
            writeIndex = (writeIndex + 1) % WINDOW
            if (writeIndex == 0) filled = true
          }
        }
      }
    }
  }

  private fun stop() {
    if (!running) return
    running = false
    thread?.quitSafely()
    thread = null
    recorder?.let {
      runCatching { it.stop() }
      it.release()
    }
    recorder = null
  }
}
```

`modules/pitch-input/ios/PitchInputModule.swift`:

```swift
import AVFoundation
import ExpoModulesCore

private let WINDOW = 4096

/**
 * Microphone tap for the tuner. Mirrors the Android module exactly: a ring of
 * the newest WINDOW frames, handed to JS as little-endian Int16 PCM. All pitch
 * detection lives in src/lib/tuner-math.ts.
 *
 * NOTE: written without a device to verify against — there is no Apple
 * developer account on this project yet. Test before trusting.
 */
public class PitchInputModule: Module {
  private let engine = AVAudioEngine()
  private var running = false
  private var ring = [Int16](repeating: 0, count: WINDOW)
  private var writeIndex = 0
  private var filled = false
  private let lock = NSLock()

  public func definition() -> ModuleDefinition {
    Name("PitchInput")

    Property("sampleRate") { 44100 }
    Property("isRecording") { self.running }

    Function("start") { try self.start() }
    Function("stop") { self.stop() }

    Function("read") { () -> Data in
      self.lock.lock()
      defer { self.lock.unlock() }
      guard self.filled else { return Data() }
      var out = Data(capacity: WINDOW * 2)
      for i in 0..<WINDOW {
        var s = self.ring[(self.writeIndex + i) % WINDOW].littleEndian
        withUnsafeBytes(of: &s) { out.append(contentsOf: $0) }
      }
      return out
    }

    OnDestroy { self.stop() }
  }

  private func start() throws {
    guard !running else { return }
    let session = AVAudioSession.sharedInstance()
    // .measurement leaves the signal alone — no AGC or processing shaping the pitch.
    try session.setCategory(.playAndRecord, mode: .measurement, options: [.defaultToSpeaker])
    try session.setActive(true)

    lock.lock()
    writeIndex = 0
    filled = false
    lock.unlock()

    let input = engine.inputNode
    let format = input.outputFormat(forBus: 0)
    input.installTap(onBus: 0, bufferSize: 1024, format: format) { [weak self] buffer, _ in
      guard let self, let channel = buffer.floatChannelData?[0] else { return }
      self.lock.lock()
      for i in 0..<Int(buffer.frameLength) {
        let clamped = max(-1, min(1, channel[i]))
        self.ring[self.writeIndex] = Int16(clamped * 32767)
        self.writeIndex = (self.writeIndex + 1) % WINDOW
        if self.writeIndex == 0 { self.filled = true }
      }
      self.lock.unlock()
    }

    engine.prepare()
    try engine.start()
    running = true
  }

  private func stop() {
    guard running else { return }
    running = false
    engine.inputNode.removeTap(onBus: 0)
    engine.stop()
    try? AVAudioSession.sharedInstance().setActive(false, options: .notifyOthersOnDeactivation)
  }
}
```

`src/lib/tuner-input.ts`:

```ts
// Bridge between the native mic tap and the pure pitch math: permissions,
// lifecycle, and the Int16-bytes → Float32-samples conversion.
import { requestRecordingPermissionsAsync } from 'expo-audio';

import PitchInput from '../../modules/pitch-input';

export type TunerStatus = 'ok' | 'no-module' | 'denied' | 'error';

/** Little-endian Int16 PCM → normalized floats. The Int16Array view is free;
 *  only the float conversion costs anything. */
export function bytesToSamples(bytes: Uint8Array): Float32Array {
  const pcm = new Int16Array(bytes.buffer, bytes.byteOffset, bytes.byteLength >> 1);
  const out = new Float32Array(pcm.length);
  for (let i = 0; i < pcm.length; i++) out[i] = pcm[i] / 32768;
  return out;
}

export async function startInput(): Promise<TunerStatus> {
  if (!PitchInput) return 'no-module';
  const { granted } = await requestRecordingPermissionsAsync();
  if (!granted) return 'denied';
  try {
    PitchInput.start();
    return 'ok';
  } catch {
    return 'error';
  }
}

export function stopInput() {
  try {
    PitchInput?.stop();
  } catch {
    // stopping a mic that is already gone is not worth surfacing
  }
}

/** null until the ring has filled once. */
export function readSamples(): Float32Array | null {
  const bytes = PitchInput?.read();
  if (!bytes || bytes.byteLength === 0) return null;
  return bytesToSamples(bytes);
}

export const sampleRate = () => PitchInput?.sampleRate ?? 44100;
```

### Task 6: The tuner screen

**Files:**
- Create: `src/app/tuner.tsx`

**Interfaces:**

- Produces: the route `/tuner`.

**Design requirements — all of these are load-bearing, not decoration:**

1. **Poll at 40 ms** with `setInterval` inside a `useFocusEffect`. Start the mic on focus, `stopInput()` on blur. A tuner that holds the microphone in the background earns one-star reviews.
2. **Arc gauge**, `react-native-svg`, spanning ±50 cents. The needle is a Reanimated **spring** (`withSpring`) on a shared value, never `withTiming` — the overshoot-and-settle is what makes it read as a physical instrument.
3. **Colour is the primary signal.** Arc stroke interpolates `C.tertiary` → `C.accent` → `C.success` as `|cents|` falls. Under 5 cents: a success-tinted halo blooms behind the note and the glyph scales to 1.04.
4. **Exactly one `Haptics.selectionAsync()`** on the transition into lock. None on leaving. It must never buzz while a peg is being turned.
5. **Note readout** centred: name in `F.accent` (Newsreader italic) at ~96pt with `#` rendered as `♯`, octave as a small superscript, live cents underneath in `F.body`.
6. **String row** when the instrument is not `chromatic`: one dot per string, the `nearestString` target lit, each dot filling as it comes into tune. Tapping a dot pins that string; tapping again unpins.
7. **Header row**: instrument picker and reference-A stepper (415–445, 1 Hz steps), both persisted via `updateSettings`.
8. **`reduceMotion`**: springs become direct `.value =` assignment, the halo becomes a static border. Same contract as `src/components/motifs.tsx`.
9. **Status cards** for `no-module`, `denied` (with an `openSettings` button via `Linking.openSettings()`), and `error` (with retry). Never a dead gauge.
10. **Only `note.name`, `octave`, the pinned string, and the status go through React state.** Cents, colour, needle angle, and halo are Reanimated shared values driven from the same poll tick — the tree must not re-render 25 times a second.
