## Gotchas & notes

- **Committing from a shared working tree.** Three sessions edited `store.tsx`,
  `profile.tsx`, `progress.tsx`, `piece/[id].tsx` and both locale files at once, and
  one had `git rm`'d four wav files into the shared index. `6addf6d` was built as
  *HEAD + only my substitutions* per shared file (`git hash-object -w` +
  `git update-index --cacheinfo`), verified in a throwaway worktree, and committed
  through a copied `GIT_INDEX_FILE` with the foreign deletions reset. If you find a
  future commit that "contains someone else's hunk", this is why splitting was hard.
- **Local `node_modules` is broken.** No `.bin`, no `@expo/env`; `npx expo config`
  fails in the main tree, which makes `eas update` and `eas build` fail before
  uploading. The builds were made from `C:\dev\x\etude-release`, a `git worktree` at
  HEAD with its own `npm ci`. Either `npm ci` in the main tree or keep using the
  worktree (`git -C ../etude-release checkout --detach <sha>` then `npm ci`).
- **`Session.at` is only set for same-day logs.** Backdated logs have no time of
  day, so `byTimeOfDay` and the time-of-day driver skip them by design.
- **`streakSurvival` ignores break days and grace.** Plain consecutive days; noted
  with a `ponytail:` comment.
- **`streakSurvival` uses Object.entries on integer keys** for the weekday mode, so a
  tie resolves to the lowest weekday. The check asserts that.
- **Git Bash heredocs over ~100 lines failed** with "unexpected EOF" in this
  environment. Long edits were written to the scratchpad with the Write tool and run
  as `python script.py`. `$TMPDIR` is still empty here — use absolute paths.
- **Recap "Best-rated piece" and the projection row** push the year card to five
  candidate rows; `rows()` still caps at four, so the last non-null one drops when
  all are present.
